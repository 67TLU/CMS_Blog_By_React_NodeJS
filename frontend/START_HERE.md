# Portal News Frontend

Frontend React đã được nối với API backend. Đọc `INTEGRATION_GUIDE.md` để thiết lập môi trường và chạy dự án.

1. Tạo `.env` từ `.env.example`.
2. Chạy `npm install`.
3. Chạy `npm run dev`.
4. Backend phải chạy ở `http://localhost:4000` và `FRONTEND_URL` của backend phải là `http://localhost:5173`.

Không chép `.env` hoặc secret vào kho mã nguồn.
